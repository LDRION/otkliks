# Редизайн сайта Откликса

Прототипы нового вида сайта — до переноса в `apps/marketing-site`. Рабочую версию не трогаем,
старый вид сохранён: репозиторий `LDRION/otkliks-old` и тег `visual-before-redesign`.

- `landing-v1.src.html` — лендинг, версия 1 (03.10.2026): тёмный «экран», жидкое стекло
  над пятнами фирменных цветов, крупная типографика, подробности — во всплывашках при
  наведении. Логотип подставляется вместо `__LOGO_PATH__` (путь из лаунчера).
  Просмотр — приватный артефакт: https://claude.ai/artifact/SJHod8625KvZv7g2Dcn7Ju

- `landing-v2.src.html` — лендинг, версия 2 (03.10.2026): светлая рамка с волосяными линиями,
  живой интерфейс лаунчера, цветные блоки возможностей. Ориентир — лендинг в духе Dub
  (saaslanding.pro/dub-replica). Превью: https://claude.ai/artifact/PBtdYXjpWEuH6ad7uvUT6R

Ориентиры владельца: тёмный UI-лендинг с плавающими элементами интерфейса и неоновыми
акцентами; «жидкое стекло» поверх цветных пятен; большой текст и мало текста на виду.
Цвета — наши: бирюзовый #12edcf, тёмно-синий #212d4e, плюс холодный синий из тёмной темы.
